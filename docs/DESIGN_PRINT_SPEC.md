# Design & Print Spec

이 문서는 이력서의 시각적 방향과 A4 PDF 출력 기준을 정리합니다.

## 1. 전체 디자인 방향

### 확정

Surfit 이력서 레퍼런스처럼 다음 특성을 지향합니다.

- 깔끔함
- 모던함
- 넉넉한 여백
- 정보 위계가 명확한 레이아웃
- 과도한 장식 최소화

페이지 수를 먼저 정한 뒤 내용을 억지로 끼워 맞추지 않습니다.

---

## 2. Timeline 디자인

### 확정

단순 텍스트 연혁보다 시간 흐름을 한눈에 볼 수 있는 구조를 사용합니다.

- 중앙 세로축
- 최신 → 과거 순
- 좌우 교차 배치

타임라인은 상세 내용을 설명하는 섹션이 아니라 전체 경험의 흐름을 빠르게 파악하게 하는 역할입니다.

---

## 3. PDF 출력

### 확정

- 채용 제출용 최우선 결과물은 PDF
- A4 기준 출력
- 1p / 2p / 3p처럼 페이지 수를 미리 고정하지 않음
- 내용에 따라 자연스럽게 페이지가 늘어남
- 가독성을 페이지 수보다 우선

### 페이지 분할 원칙

- 페이지 수를 맞추기 위해 글자 크기를 억지로 줄이지 않음
- 프로젝트나 경력 항목이 페이지 사이에서 어색하게 찢어지지 않게 함
- 섹션 제목만 페이지 하단에 홀로 남지 않게 함
- 정보 위계와 읽기 흐름을 우선

---

## 4. 편집 화면과 출력 결과

### 확정

편집 앱은 화면에서 내용을 직접 선택해 수정하는 Resume Builder 형태의 사용성을 지향합니다.

출력 결과는 웹 편집 UI와 분리해 채용 제출용 문서로 읽기 좋게 보여야 합니다.
