# Resume Structure

이 문서는 이력서에 어떤 정보를 어떤 역할로 배치할지 정리합니다.

## 1. 역할 분리

### 확정

- **이력서**: 프로젝트와 경력의 요약, 면접 질문의 출발점
- **포트폴리오**: 상세 스토리, 판단 과정, 문제 해결 과정을 설명하는 문서

기존 7페이지 이력서처럼 프로젝트의 세부 과정을 길게 반복하지 않습니다.

## 4. Projects

### 확정

프로젝트는 Abstract 수준으로 짧게 요약합니다.

프로젝트별 편집 항목:

- 프로젝트명
- 프로젝트 한 줄 정의
- 기간
- 팀 규모
- 역할
- 짧은 Abstract
  - 왜/무엇을 위한 프로젝트인지
  - 내가 무엇에 관여했는지
  - 대표 결과/임팩트
- 관련 링크
- 표시 여부

기존 이력서에 있던 아래 상세 내용은 원칙적으로 포트폴리오에서 다룹니다.

- 상세 GA4 퍼널 수치와 분석 과정
- UT 문제 발견 과정
- 정책 변경 상세
- 자동화 구현 상세
- QA 상세
- 기술 선택/검증의 세부 과정

## 11. 지원처별 재구성

### 확정

하나의 마스터 데이터를 기준으로 지원처별 이력서 버전을 만들 수 있게 합니다.

지원처별로 변경할 수 있는 요소:

- 지원 직무명
- 자기소개
- 프로젝트 순서

- 강조 항목

웹툰·인터넷방송·콘텐츠·서브컬처·게임 등 여러 분야에 지원할 수 있으므로 기본 구조를 특정 도메인 하나에 고정하지 않습니다.
