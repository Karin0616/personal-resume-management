# personal-resume-management

개인 이력서 관리 과정을 단순화하기 위한 개인용 프로그램입니다.

현재는 구현에 앞서 **문서와 의사결정 기준을 먼저 고정하는 단계**입니다. 확정된 내용과 아직 정하지 않은 내용을 섞지 않고 관리합니다.

## 현재 확정된 방향

- 배포: **Vercel**
- Cloudflare: 이 프로젝트의 기본 인프라에서는 사용하지 않음
- 인증 방향: **공개키 기반 challenge-response**
- 저장소: public repository
- 보안 원칙: 개인정보, 비밀키, 토큰 등 민감정보는 저장소에 커밋하지 않음

## 문서 상태 표기

문서 안에서는 아래 세 상태를 구분합니다.

- **확정**: 대화나 구현 결정으로 이미 정한 내용
- **가설**: 현재 방향을 잡기 위한 초안이며 변경 가능
- **TBD**: 아직 결정 근거가 부족해 보류한 내용

## Repository policy

이 저장소는 공개 저장소이므로 실제 이력서 원문에 포함된 전화번호, 이메일 등 개인정보나 인증용 비밀정보를 직접 저장하지 않습니다.

구현 과정에서 새로운 결정이 생기면 코드보다 먼저 또는 같은 커밋에서 관련 문서를 갱신합니다.
